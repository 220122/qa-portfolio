# BUG-002 上传非法文件时返回 500，且失败后残留文件

| 字段 | 内容 |
|---|---|
| 缺陷编号 | BUG-002 |
| 所属项目 | course-rag-agent |
| 关联用例 | `test_documents.py::test_upload_invalid_file[空文件/扩展名伪装/伪造pdf头]` |
| 关联风险项 | R-02 |
| 严重程度 | 一般 |
| 优先级 | 高 |
| 状态 | 已复现，待修复 |

## 环境

同 BUG-001。

## 前置条件

后端已启动。

## 复现步骤与结果（3 个同类场景，同一根因）

| # | 场景 | 请求 | 实际结果 |
|---|---|---|---|
| 1 | 空文件 | `filename=空文件.docx`，内容 0 字节 | **500** `{"detail":"文档处理失败：Package not found at './data/uploads\\空文件.docx'"}` |
| 2 | 扩展名伪装 | `filename=伪装.docx`，内容为纯文本 | **500** `{"detail":"文档处理失败：Package not found at './data/uploads\\伪装.docx'"}` |
| 3 | 伪造 pdf 头 | `filename=伪装.pdf`，内容 `%PDF-1.4 fake` | **500** 响应体只有 `Internal Server Error`（- 未走统一错误处理，无 detail） |

复现脚本：

```python
import requests
cases = [
    ("空文件.docx", b"", "application/vnd.openxmlformats-officedocument.wordprocessingml.document"),
    ("伪装.docx", "这是纯文本".encode(), "application/vnd.openxmlformats-officedocument.wordprocessingml.document"),
    ("伪装.pdf", b"%PDF-1.4 fake", "application/pdf"),
]
for name, content, mime in cases:
    r = requests.post(
        "http://127.0.0.1:8000/api/documents/upload",
        files={"file": (name, content, mime)}, timeout=60,
    )
    print(name, r.status_code, r.text[:120])
```

## 预期结果

- 状态码 **400**（用户传错文件属客户端错误，不是服务端故障）
- `detail` 是用户可读的提示，例如"文件内容为空或已损坏，请重新导出后再上传"
- 服务端**不留下任何文件**

## 实际结果

- 三个场景全部返回 **500**，其中第 3 个连 `detail` 都没有（`Internal Server Error`），前端无法给出任何引导
- **上传失败后 `data\uploads\伪装.pdf`（0 KB）残留**，未被清理

## 影响

1. **错误码语义错误**：调用方/前端无法区分"参数错"（改参数即可）与"服务故障"（应重试），只能盲目重试或直接判为系统不可用
2. 无 detail 的 500 会让问题无法定位（现场只看到 `Internal Server Error`）
3. 失败文件残留会造成磁盘堆积

## 定位线索

`backend/main.py`：

```python
ext = os.path.splitext(file.filename)[1].lower()
if ext not in ALLOWED_EXTENSIONS:
    raise HTTPException(status_code=400, detail="仅支持 PDF / DOCX 格式文件")
```

只校验**扩展名**，不校验文件头（docx 应为 ZIP 的 `PK\x03\x04`，pdf 应为 `%PDF-`）；随后解析异常被统一包成 500。
场景 3 连 `detail` 都没有，说明异常发生在 `try/except` 覆盖范围之外。

## 建议修复

1. 增加文件头（magic number）校验，不匹配直接 400
2. 解析类异常改抛 400，并给出可读提示；保留 500 只用于真正的服务端故障
3. 用 `try/finally` 保证失败时删除已落盘文件
4. 统一异常处理器（`@app.exception_handler`），避免裸 500 无 detail
