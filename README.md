## 被测系统：课程知识问答 RAG 智能体

- **被测对象**：基于课程教材的问答系统。课件上传 → 解析 → 语义切块 → 向量化入库 → 相似度检索 → 大模型作答；检索不到相关内容时**强制拒答**，并提供评测信息（是否命中、命中片段与相似度）
- **技术栈**：FastAPI + ChromaDB + BGE-small-zh 本地向量化 + DeepSeek + Vue3
- **接口清单**：6 个（健康检查 / 上传 / 列表 / 删除 / 问答 / 评测记录）

### 测试范围与方法

| 维度 | 内容 |
|---|---|
| 功能主流程 | 上传 → 入库 → 提问 → 作答 → 评测记录 → 删除 |
| 参数校验 | 空值、缺字段、类型错误、纯空白、超长输入 |
| 文件与安全 | 扩展名白名单、文件内容伪装、伪造文件头、文件名路径穿越 |
| AI 应用专项 | 拒答准确性、Prompt 注入、多轮一致性、并发不串台、响应时间 |
| 用例设计方法 | 等价类 / 边界值 / 场景法 / 状态迁移 / 错误推测法 |
| 测试层次 | 接口层（主力）→ UI 层（冒烟）→ 评测集（AI 质量回归） |

### 结果摘要

| 指标 | 数值 |
|---|---|
| 人工设计用例 | **28 条**（见 `test-cases/course-rag-agent-接口测试用例.csv`） |
| 接口自动化用例 | **25 条**（`pytest --collect-only` 实测） |
| 执行结果 | **18 通过 / 6 失败 / 1 跳过，耗时 24.04s** |
| 缺陷 | **5 类**（4 个功能/安全缺陷 + 1 个 AI 质量缺陷） |
| 评测集 | **30 条**（课内 20 / 课外 10），实测**误拒答率 20.0% / 漏拒率 0.0%** |

**主要发现**

1. **上传文件名可路径穿越（严重）**：`filename=../../evil.docx` 被原样接受，文件被写入上传目录之外（`backend\evil.docx`）并成功入库，可被检索问答
2. **上传非法文件返回 500 而非 4xx**：空文件、扩展名伪装、伪造 pdf 头三个场景全部 500，其中伪造 pdf 头连 `detail` 都没有；失败后 `uploads\伪装.pdf` 残留未清
3. **删除不存在的文档返回 200「删除成功」**：假成功，前端会提示成功并从列表移除，刷新后复现
4. **纯空格提问绕过参数校验**：`min_length=1` 挡不住 `"   "`，请求被当正常问题处理并写入评测记录
5. **课内问题误拒答率 20%（4/20）**：进程调度算法、SPOOLing、inode、写时复制等教材核心知识点被拒答；同时漏拒率 0%，说明阈值偏严——防编造做得好，但代价是每 5 个课内问题就有 1 个答不出来，且该指标目前无监控
